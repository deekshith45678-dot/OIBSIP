
# Thermo — Temperature Converter

A responsive temperature converter built with HTML, CSS and vanilla JavaScript as part of the Oasis Infobyte Web Development and Designing Internship, Level 1.

## Features

- Convert between Celsius, Fahrenheit and Kelvin
- Validate empty and invalid numeric input
- Reject temperatures below absolute zero
- Swap source and target units
- Automatically update results when units change
- Responsive dark interface with violet accents
- Accessible form labels and error messages

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Project Structure

- index.html — converter interface
- style.css — layout and responsive styling
- script.js — conversion logic and validation
- README.md — project documentation
- screenshots/ — project screenshots

## Run Locally

1. Open this folder in Visual Studio Code.
2. Open `index.html` using Live Server, or open it directly in a browser.
3. Enter a temperature, select the source and target units, and click Convert temperature.
