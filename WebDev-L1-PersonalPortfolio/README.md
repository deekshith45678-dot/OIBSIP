
# Personal Portfolio — Sai Deekshith

A responsive personal portfolio website showcasing my background,
technical skills, projects, and interests in web development and AI/ML.

## Features

- Modern dark theme with violet accents
- Responsive desktop and mobile layouts
- Sticky navigation with mobile menu
- About, Skills, Projects, Journey, and Contact sections
- CSS animations and scroll-reveal effects
- Direct email contact link
- Project showcase featuring Smart AgriSense and Smart Healthcare System

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## How to Run

1. Download or clone the repository.
2. Open this folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
