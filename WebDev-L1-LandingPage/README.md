
# Elevate — Landing Page

## About the Project
Elevate is a modern, responsive landing page created as part of the Oasis Infobyte SIP Web Development and Designing Internship (Level 1).

The page focuses on inspiring visitors through a clean layout, bold typography, purple accents, and responsive navigation.

## Features
- Sticky navigation with Home, About, Features, and Contact links
- Hero section with headline and call-to-action buttons
- About section introducing the concept
- Three feature cards: Imagine, Create, and Grow
- Contact section and footer
- Responsive layout for desktop and mobile screens
- Mobile navigation menu
- Smooth scrolling and hover effects

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
